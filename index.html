Add game
Copy the store page link, then tap Paste — a Steam, PlayStation or Xbox link fills in what it can. A Steam link also works as steam://store/<appid> or steam://run/<appid> to launch straight into the client.
There is no search box here because no game database works from a browser without a server to proxy through — RAWG, IGDB, Giant Bomb and Steam's own API all decline cross-origin requests. A store link is the one thing that can be read without asking anyone, so the rest is filled in by hand.
